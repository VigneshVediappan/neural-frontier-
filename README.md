  <b>A futuristic top-down survival shooter built with Python and Pygame.</b>

## 👾 Enemy Types

### Hunter Drone
Balanced enemy with standard movement and attacks.

### Assassin Drone
Faster enemy designed to flank the player.

### Tank Drone
Slow but heavily armored enemy with stronger attacks.

## ⚡ Neural Laser

Press **ENTER** to activate the Neural Laser.

The laser:

- Lasts for 5 seconds
- Follows the mouse
- Penetrates walls
- Deals continuous damage
- Stops when it reaches the first enemy
- Cannot damage enemies behind the first target
