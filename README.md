# NEURAL FRONTIER
![NEURAL FRONTIER Gameplay](screenshot.png)
A futuristic top-down survival shooter built with Python and Pygame.

## Features

- Futuristic sci-fi combat
- 10 levels
- 10 unique bosses
- Multiple enemy types
- Boss-specific attacks
- Mouse aiming
- Continuous shooting
- Bouncing bullets
- Power-ups
- Health and shield systems
- Triple-shot and rapid-fire upgrades
- Futuristic grid arenas
- Animated player drone
- Particle effects
- Pause system
- Victory and game-over screens

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Arrow Keys | Move |
| Mouse | Aim |
| Hold Space | Shoot |
| P | Pause |
| C | Controls |
| ESC | Menu |
| R | Restart |

## Requirements

- Python 3.12+
- Pygame
